# Base de connaissance — chat-roles

La mémoire longue de chat-roles, le mod Claude Code qui attribue chaque message du flux.
Elle dit le *pourquoi*, les invariants et les décisions ; le code dit le *comment*.
Avant d'agir sur un sujet, ouvre l'index qui le couvre.

- [`DAT/`](DAT/README.md) — architecture technique : stack, arborescence, commandes, composants.
- [`DAF/`](DAF/README.md) — architecture fonctionnelle : qui est qui dans le flux, et comment on le montre.
- [`REGLES/`](REGLES/README.md) — process, workflows, consignes, normes et lois du projet.
- [`MOTEUR.md`](MOTEUR.md) — l'outillage Claude du projet (`.claude/`) et quand s'en servir.
- [`HISTORY.md`](HISTORY.md) — les sujets déjà traités, pour ne pas refaire deux fois le chemin.
